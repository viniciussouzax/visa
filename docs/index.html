FAQ

Perguntas Frequentes

💬 Como meus clientes enviam os dados?
Você gera um link único para cada cliente. Ele preenche o questionário DS-160 em português, de qualquer dispositivo. Os dados vão direto para seu dashboard de revisão.
💬 O sistema realmente submete no site oficial?
Sim. Após sua aprovação, a automação acessa o CEAC, resolve o captcha, preenche todas as 21 páginas e submete. Você recebe o Application ID pronto para o agendamento.
💬 Consigo personalizar o formulário com minha marca?
Sim. Oferecemos white-label com seu logo, cores e domínio personalizado. Seus clientes têm uma experiência profissional e consistente com sua marca.
💬 E se o site do CEAC cair durante a submissão?
O sistema tem retry automático com backoff inteligente. Se der timeout, tenta novamente. Todo o progresso é salvo e rastreado no seu dashboard.
💬 Funciona para famílias e grupos?
Sim. Dados compartilhados (endereço, viagem, pagador) são replicados automaticamente entre membros da família. 4 pessoas em ~8 minutos vs ~6 horas manualmente.
💬 Quanto tempo minha equipe leva para aprender?
Zero treinamento técnico. O formulário é simples como um cadastro online e o dashboard é intuitivo. Sua equipe usa desde o primeiro dia.
